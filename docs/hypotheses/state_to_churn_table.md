# State to Churn Hypothesis Table

Phase 2 で state とチャーン予兆の相関を見るための仮説表です。  
本表は実測ではなく、P0B-1 で定義した 7 種 state を起点にした初期 hypothesis を整理したものです。

| state | churn_risk_hypothesis | assumed_signal | recommended_intervention | evidence_level |
| --- | --- | --- | --- | --- |
| 来店頻度低下 | 来店間隔が伸びており、無介入だと自然離反へ進む可能性が高い | 最終来店日からの経過日数増加、来店頻度の前月比低下 | 来店理由を再提示する LINE 配信と再来店導線の設計 | hypothesis_low |
| 予算逼迫 | 価格以外の魅力より支出抑制が優先され、来店停止につながる可能性がある | 客単価低下、低価格帯商品の閲覧増加、クーポン反応偏重 | 低負担オファーの提示と価格以外の価値訴求の切り分け | hypothesis_low |
| 多忙 | 来店意欲は残っていても時間制約で後回しになり、接点消失へ進む可能性がある | 営業時間外の閲覧増加、予約途中離脱、短文応答化 | 予約負荷の低い導線、短時間で完了する提案、リマインド最適化 | hypothesis_low |
| 比較疲れ | 選択肢過多で意思決定が止まり、他社または無購買へ流れる可能性がある | 比較ページ往復、検討期間長期化、閲覧カテゴリの拡散 | 選択肢を絞った提案と比較理由の明文化 | hypothesis_low |
| 限定感志向 | 希少性訴求がないと行動優先度が上がらず、来店が先送りされる可能性がある | 限定訴求への反応、先着企画の閲覧、通常配信の反応鈍化 | 期間限定・先着訴求を含むメッセージ配信 | hypothesis_low |
| 価格感度高 | 値引き有無で反応差が大きく、通常価格では離脱しやすい | 値引き時のみ反応、クーポン利用率上昇、価格比較行動 | 割引条件の明確化と不必要な高単価訴求の抑制 | hypothesis_low |
| 接触希薄化 | 接点そのものが減っており、放置すると休眠顧客へ移行する可能性がある | 開封率低下、既読後未反応、接触チャネル数の減少 | 接触頻度の再設計と反応しやすいチャネルでの再接続 | hypothesis_low |

## Note

- evidence_level は現時点ではすべて仮説段階のため `hypothesis_low` とする
- 後続タスクで Meta と KPI の実測が集まり次第、仮説強度を更新する
